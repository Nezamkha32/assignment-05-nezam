##  Assignment Questions & Answers
1️⃣ What is the difference between var, let, and const?
###  1️⃣ Difference between var, let, and const
- **var** → Function-scoped, can be redeclared and updated.  
- **let** → Block-scoped, can be updated but not redeclared in the same scope.  
- **const** → Block-scoped, cannot be reassigned (but objects/arrays can be mutated).

---
2️⃣ What is the spread operator (...)?
### 2️⃣ Spread operator (...)
- Expands iterable elements (arrays/objects) into individual elements.  


const arr = [1, 2, 3];
const newArr = [...arr, 4]; // [1,2,3,4]

------
3️⃣ What is the difference between map(), filter(), and forEach()?
#### 3️⃣ Difference between map(), filter(), and forEach()

- map() → Returns a new array after applying a function.

- filter() → Returns a new array with elements that pass a condition.

- forEach() → Executes a function for each element but returns nothing.  

----------
4️⃣ What is an arrow function?
#### 4️⃣ Arrow function
Shorter syntax for writing functions.

const add = (a, b) => a + b;

------------

5️⃣ What are template literals?
#### 5️⃣ Template literals
Strings enclosed in backticks (`) that allow embedding variables and expressions using ${}.
const name = "Nezam";
console.log(`Hello, ${name}!`);
